# Практикум группы 2 Три светофора

## Задача

По предыдущим данным спрогнозировать задержки у трёх равноудалённых светофоров A, B и C через заданное время и выбрать выезд с минимальным ожиданием. Писать модель с нуля не требуется: нужно сравнивать готовые решения, менять по одному параметру и объяснять результат.

## Запуск

```bash
python3 -m pip install -r requirements.txt
jupyter lab
```

Откройте `practicum.ipynb` и выполните **Kernel → Restart Kernel and Run All Cells**. Результаты каждого запуска появятся в отдельной папке внутри `outputs_traffic_lights`.

## Что фиксировать после каждого запуска

| Запуск | FORECAST_MINUTES | NOISE_LEVEL | INCIDENT_PROBABILITY | Модель | MAE | Правильный выбор | Лишнее ожидание |
|---|---:|---:|---:|---|---:|---:|---:|
| Исходный | 60 | 0.9 | 0.012 | | | | |
| Ближний прогноз | 30 | 0.9 | 0.012 | | | | |
| Дальний прогноз | 120 | 0.9 | 0.012 | | | | |
| Больше шума | 60 | 2.0 | 0.012 | | | | |
| Больше заторов | 60 | 0.9 | 0.05 | | | | |

В каждой строке сравните baseline, Ridge и MLP. За один запуск меняйте только один параметр.

## Последовательность работы

1. Запустите исходный вариант без изменений при `RUN_FINAL_TEST = False`.
2. Откройте `metrics.csv`, `forecast.png` и `first_20_decisions.csv`.
3. Сравните baseline, Ridge и MLP по трём метрикам.
4. Установите `FORECAST_MINUTES = 30` и оцените ближний прогноз.
5. Установите `FORECAST_MINUTES = 120` и оцените дальний прогноз.
6. Верните `FORECAST_MINUTES = 60`, установите `NOISE_LEVEL = 2.0`.
7. Верните `NOISE_LEVEL = 0.9`, установите `INCIDENT_PROBABILITY = 0.05`.
8. Изучите результат эксперимента с утечкой будущего и найдите запрещённые признаки.
9. Выберите модель по validation. Основная метрика — `mean_extra_wait_minutes`.
10. Верните лучшие параметры и только один раз установите `RUN_FINAL_TEST = True` для финальной проверки.

## Ожидаемый исходный результат

При `SEED = 42` ориентир такой:

| Модель | MAE минуты | Правильный выбор | Лишнее ожидание минуты |
|---|---:|---:|---:|
| Последнее значение | около 1.79 | около 0.60 | около 0.65 |
| Ridge | около 1.47 | около 0.64 | около 0.54 |
| MLP | около 1.44 | около 0.59 | около 0.70 |

Эксперимент с утечкой будущего показывает почти нулевую ошибку и почти 100 процентов правильных решений. Этот результат использовать нельзя.

## Правильные выводы

- Самая низкая MAE не гарантирует лучший выбор маршрута.
- Для практической задачи главная метрика — среднее дополнительное ожидание.
- В исходном эксперименте Ridge полезнее MLP, хотя MLP немного лучше по MAE.
- Более дальний прогноз обычно сложнее ближнего.
- Шум и случайные заторы ухудшают предсказуемость.
- Будущие значения нельзя использовать как входные признаки.
- Test применяется один раз после выбора модели и параметров на validation.
