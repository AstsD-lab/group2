# Практикум группы 2 Три светофора

## Задача

По предыдущим данным спрогнозировать задержки у трёх равноудалённых светофоров A, B и C через заданное время и выбрать выезд с минимальным ожиданием. Писать модель с нуля не требуется: нужно сравнивать готовые решения, менять по одному параметру и объяснять результат.

## Запуск

```bash
python3 -m pip install -r requirements.txt
jupyter lab
```

Откройте `practicum.ipynb` и выполните **Kernel → Restart Kernel and Run All Cells**. Результаты каждого запуска появятся в отдельной папке внутри `outputs_traffic_lights`.

## Что фиксировать после каждого запуска

| Запуск | FORECAST_MINUTES | NOISE_LEVEL | INCIDENT_PROBABILITY | Модель | MAE | Правильный выбор | Лишнее ожидание |
|---|---:|---:|---:|---|---:|---:|---:|
| Исходный | 60 | 0.9 | 0.012 | | | | |
| Ближний прогноз | 30 | 0.9 | 0.012 | | | | |
| Дальний прогноз | 120 | 0.9 | 0.012 | | | | |
| Больше шума | 60 | 2.0 | 0.012 | | | | |
| Больше заторов | 60 | 0.9 | 0.05 | | | | |

В каждой строке сравните baseline, Ridge и MLP. За один запуск меняйте только один параметр.

Необходимо исследовать систему выбора одного из трёх равноудалённых светофоров. Система должна по предыдущим данным определить, через какой светофор выгоднее выезжать в будущем.

Сначала запустите исходную конфигурацию без изменений и сравните:

baseline последнего значения;

линейную модель Ridge;

нейросеть MLP.

Для каждой модели зафиксируйте:

MAE в минутах;

долю правильного выбора светофора;

среднее дополнительное ожидание.

После этого изучите параметры в начале ноутбука. Определите, за что отвечает каждый параметр, и сформулируйте гипотезы о его влиянии на прогноз и выбор маршрута.

Дальнейшие значения параметров вы выбираете самостоятельно.

Правило эксперимента: за один запуск изменяется только один параметр. Перед запуском запишите ожидаемый результат. После запуска зафиксируйте фактические метрики и объясните полученное изменение.

Необходимо определить:

как горизонт прогноза влияет на результат;

как шум измерений влияет на разные модели;

как случайные заторы влияют на прогноз;

как количество исторических данных влияет на качество;

всегда ли модель с лучшей MAE лучше выбирает маршрут;

какие параметры оказывают наибольшее влияние.

Отдельно найдите эксперимент с утечкой будущих данных и объясните, почему его практически идеальному результату нельзя доверять.

Во время исследования RUN_FINAL_TEST должен оставаться равным False. Финальный test запускается один раз после окончательного выбора модели и конфигурации.

На выходе требуется:

таблица минимум из пяти запусков;

старое и новое значение изменённого параметра;

метрики каждого запуска;

один основной график;

выявленные зависимости;

обоснованный выбор модели;

объяснение утечки данных;

результат однократной финальной проверки;

предложение следующего эксперимента и перечень необходимых реальных данных..
